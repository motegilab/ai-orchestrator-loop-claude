Q2

事前に人間が作るべき環境

  1. 1
    Claude アカウント & サブスクリプション

    claude.ai にアクセスして Pro または Max プランを契約する。
    → https://claude.ai/upgrade

  2. 2
    Git インストール

    macOS: brew install git または Xcode Command Line Tools
    Windows: Git for Windows（https://git-scm.com）をインストール

  3. 3
    GitHub アカウント & リポジトリ作成

    github.com でアカウント作成済みであればOK。
    新規リポジトリ名: ai-orchestrator-loop（または任意名）

  4. 4
    Python 3.9以上 インストール確認

    ターミナルで python3 --version を実行。3.9未満なら https://python.org からインストール。

  5. 5
    VS Code インストール（推奨）

    https://code.visualstudio.com からインストール。
    拡張機能: Claude for VS Code（任意）

  6. 6
    Claude Code CLI インストール

    ターミナルで以下を実行（ネイティブインストーラー推奨）:

    # macOS / Linux curl -fsSL https://claude.ai/install.sh | bash source ~/.bashrc # または source ~/.zshrc claude --version # 確認 # Windows (PowerShell) irm https://claude.ai/install.ps1 | iex claude --version
  7. 7
    Claude Code にログイン

    以下を実行してブラウザでauth:

    claude # 初回起動でログインプロンプトが出る # ブラウザが開くので claude.ai アカウントでログイン
  8. 8
    ローカルフォルダの準備（Google Drive 利用中の場合）

    Google Drive 同期フォルダ内には置かないことを推奨。
    理由: Hookが頻繁にファイル書き込みをするため、Drive同期と競合する可能性がある。
    推奨場所: ~/projects/ai-orchestrator-loop/

    mkdir -p ~/projects cd ~/projects git clone https://github.com/YOUR/ai-orchestrator-loop.git # または今回ダウンロードしたファイルをここに置く
Google Drive について
コードリポジトリ本体は ~/projects/ に置く。runtime/ フォルダ（実行生成物）だけを Google Drive でバックアップしたい場合は、runtime/ にシンボリックリンクを作る方法がある。ただし v1 では不要。
Q3

環境設定後、最初に打つべきプロンプト

Step 1: セットアップ（1回だけ）

# プロジェクトフォルダに移動 cd ~/projects/ai-orchestrator-loop # 初回セットアップ（環境チェック + hashの初期化） make setup

Step 2: 最初の loop-start

make loop-start

これだけでClaudeが起動し、SessionStart Hookが自動的に環境チェックとCLAUDE.mdの内容を読んで、tasks/milestones.jsonの最初のタスクを実行し始めます。

もし make が使えない環境の場合（直接 claude コマンド）

claude --add-dir ~/.claude/skills \ --allowedTools "Read,Write,Edit,MultiEdit,Bash,Task" \ -p "SSOT.mdとCLAUDE.mdを読んで、tasks/milestones.jsonの最初のタスクを実行してください。"

初回以降のプロンプト（ループ中）

基本
ループが回り始めたら、基本的に人間は何も打たない。
Claudeが止まったら → make loop-start を再度実行するだけ。
前回の続きは next_session.md を通じて自動注入される。
状況打つコマンド
通常のループ再開make loop-start
前回の状態確認make loop-status
特定タスクを指示したいclaude -p "tasks/milestones.jsonのT3を実行して"
SSOTを手動更新した後python3 .claude/hooks/ssot_gate.py --update-hash

最初のPJ展開ステップ（まとめ）

# ① 前提ツールの確認 python3 --version # 3.9以上 git --version # 任意バージョン # ② Claude Code CLI インストール curl -fsSL https://claude.ai/install.sh | bash source ~/.zshrc # または ~/.bashrc claude --version # バージョンが表示されればOK claude doctor # 環境診断 # ③ ダウンロードしたファイルをプロジェクトに配置 mkdir -p ~/projects/ai-orchestrator-loop # zipを解凍してここに配置する cd ~/projects/ai-orchestrator-loop # ④ GitHubにpush git init git add . git commit -m "feat: Claude-first orchestrator loop v1.0" git remote add origin https://github.com/YOUR/ai-orchestrator-loop.git git push -u origin main # ⑤ セットアップ（初回のみ） make setup # → Python確認 / Claude Code確認 / ssot_integrity.json初期化 # ⑥ ループ開始！ make loop-start # → SessionStart Hookが発火 → Claudeが自律的にタスクを開始する
新しいPJに展開するとき
  1. gh repo create NEW-PJ --template YOUR/ai-orchestrator-loop
  2. CLAUDE.md をPJの内容に書き換える（目的・技術スタック・key commands）
  3. SSOT.md をPJ固有のルールに書き換える（汎用ルールはそのままでOK）
  4. python3 .claude/hooks/ssot_gate.py --update-hash
  5. make loop-start
